# CantResell

Unity **6000.3.25f1** / URP / Photon Fusion 기반의 PC 4인 공동 가구점 게임 시제품입니다.

낮에는 가구를 팔거나 공동 자금으로 도박하고, 밤에는 함께 한 집에 들어가 센서를 피해 가구를 훔칩니다. 도박 손실과 경찰 벌금도 모두 공금에서 나갑니다. 방 목록·공개/비공개 입장·Fusion Voice 대화와 설정을 유지합니다.

`Assets/1. Scenes/Home.unity`에서 시작합니다. 실행 방법과 설정은 [시제품 안내](Assets/7.%20Document/PrototypeGuide.md)를 참고하세요.
